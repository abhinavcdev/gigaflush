Built like an instrument, not a chore.

One job — find rebuildable dependency bloat and remove it safely — done with the precision of a native utility.

Live scanning

Projects stream in the moment they're found, sorted by reclaimable space — no waiting for the full walk to finish.

✓ node_modules ✕ src/

Guard-railed deletes

The engine refuses to remove anything that isn't literally named node_modules — enforced in Rust, not just the UI.

Menu-bar native

A tiny Rust + Tauri tray app — a few megabytes, no Electron, no dock clutter. One click and it's there; Esc and it's gone.

8,200files/s

Fast where it counts

A parallel directory walker skips system folders and nested duplicates, so scanning an entire home directory stays quick.

Rebuildable by design

node_modules is a cache, not your code. Anything you purge comes back with npm install — nothing else is touched.
